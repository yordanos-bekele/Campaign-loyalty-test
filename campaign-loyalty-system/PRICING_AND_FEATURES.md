# Campaign Loyalty System - Pricing and Features Proposal

## Introduction

Dear Marathon Klassics Team,

We are pleased to present the Campaign Loyalty System, a comprehensive digital solution designed specifically for your beverage loyalty marketing campaign. This system enables customers to earn free beers through a simple QR code scanning mechanism at participating hotels, fostering repeat engagement and brand loyalty.

Based on the project scope, we've developed a robust platform that automates the entire loyalty process while providing powerful analytics and fraud prevention features.

## Key Features

### Core Functionality
- **QR Code Scanning**: Hotel-specific QR codes that rotate every 2 minutes for security
- **Automatic Reward System**: Customers earn a free beer after 10 valid scans at the same hotel
- **Device-Based Tracking**: Seamless identification using browser cookies and device IDs
- **Time-Based Validation**: 60-minute minimum gap between scans and 3-scan daily limit per hotel

### User Roles and Interfaces
- **Customer Portal**: Simple registration and scan interface
- **Hotel Dashboard**: Real-time performance metrics (scans, rewards, suspicious activity)
- **Admin Dashboard**: Comprehensive campaign management and analytics

### Advanced Features
- **Fraud Detection**: Automatic flagging of suspicious scanning patterns
- **Bulk Import**: Excel-based import for hotels and customers
- **Analytics Dashboard**: Detailed customer analytics, reward tracking, and campaign performance
- **Cross-Platform Compatibility**: Works on mobile browsers and supports CORS for deployed environments

### Technical Stack
- **Backend**: Spring Boot (Java) with PostgreSQL database
- **Frontend**: React-based responsive web application
- **Deployment**: Docker-ready with support for Vercel and Render platforms
- **Security**: JWT authentication, secure QR token management, and fraud monitoring
